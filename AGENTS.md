# AGENTS.md

## О проекте

`vpnlimit` — один bash-скрипт (`vpnlimit` в корне, без расширения), который ограничивает скорость на каждый IP клиента для портов Xray / 3x-ui через nftables. Интерактивное меню + CLI. Пользовательская документация — в `README.md`.

## Структура

- `vpnlimit` — весь код. Ставится в `/usr/local/bin/vpnlimit`.
- `README.md` — документация для людей. Обновляй её при любом изменении поведения, команд или меню.
- Во время работы скрипт создаёт: `/etc/vpnlimit/vpnlimit.conf` (DL, UL, PORTS), `/etc/vpnlimit/whitelist.txt`, `/etc/systemd/system/vpnlimit.service`.

## Жёсткие правила (нарушать нельзя)

- Скрипт трогает **только** таблицу `inet vpnlimit`. Никаких `flush ruleset`, никаких изменений чужих таблиц.
- Не использовать `/etc/nftables.conf` и `nftables.service`: в Debian/Ubuntu там `flush ruleset`, который ломает правила Docker и ufw. Автозагрузка — только через собственную `vpnlimit.service`.
- Любое применение правил: сначала `nft -c -f <файл>`, потом `nft -f <файл>`. Правила генерируются целиком (`table … ; delete table … ; table … { … }`) и применяются атомарно.
- Передавать правила в nft **только через временный файл** (`mktemp`), не через stdin (`nft -f -`) — на части версий nft это не работает.
- Автозагрузка по умолчанию выключена: перезагрузка должна снимать лимит, пока пользователь сам её не включил.
- Никаких внешних зависимостей сверх: bash 4+, coreutils, awk, sed, grep, iproute2 (`ss`), nftables, systemd.

## Подводные камни

- awk может быть `mawk`: не использовать возможности только gawk и классы вида `[[:space:]]` внутри awk; писать `[ \t]`.
- Числа из ввода приводить через `$((10#$n))`, иначе `08` и `09` ломают арифметику (восьмеричная система).
- Внутри скрипта есть heredoc с маркером `EOF` — не вкладывать скрипт в другой heredoc с тем же маркером.
- Не использовать `${var:+…}`, если в подстановке есть фигурные скобки (синтаксис nft) — генерировать такие строки через `if`/`echo`.
- Ввод пользователя обрезать от пробелов и `\r` по краям; адреса для белого списка дополнительно проверять через `nft -c` на временной таблице `vpnlimit_check`.
- Пустой `elements = { }` в nft недопустим — блок `elements` выводить только если список не пуст.

## Стиль

- Весь текст для пользователя — на русском. Комментарии в коде — на русском.
- Цвета только через переменные `G R Y C B D N`; при выводе не в терминал они пустые.
- Каждое действие меню заканчивается `pause`; ввод всегда с вариантом «Enter — отмена».
- Новую функцию добавлять и в меню, и в CLI (`case` в конце файла), и в `usage`.
- Функции короткие, `local` для всех переменных, без `set -e`.

## Проверка изменений

```bash
bash -n vpnlimit                       # синтаксис, обязательно
shellcheck vpnlimit                    # если установлен
```

Реальную проверку правил делать только на тестовой машине или VPS с доступом к консоли провайдера, при выключенной автозагрузке. Аварийный откат:

```bash
nft delete table inet vpnlimit
```
